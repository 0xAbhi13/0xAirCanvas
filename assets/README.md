# assets/

This folder is where the README's media should live:

- `demo.gif` — a short screen recording of you air-writing with 0xAirCanvas
- `screenshot.png` — a still shot of the main workspace
- `preview.png` — a wider preview shot for the README's Preview section

None of these are included yet. This environment has no webcam and cannot
run the live hand-tracking pipeline, so a real demo cannot be recorded here —
and a fabricated GIF or screenshot would misrepresent the project.

**Before publishing, record these yourself:**

1. Run the app locally (`python app.py`) with your webcam connected.
2. Use a screen recorder (e.g. ShareX, OBS, or the Windows Game Bar,
   `Win + G`) to capture ~10–15 seconds of drawing, then export as GIF.
3. Take a full-window screenshot for `screenshot.png` and `preview.png`.
4. Drop the files in this folder with the exact names above — the README
   already links to them.
